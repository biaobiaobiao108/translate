🛠️ 终端全局使用与 PATH 环境变量配置指引

只需简单一步重命名并移入 PATH 目录，即可在系统任意终端直接敲 tran 全局畅享翻译

1 重命名并移入 PATH 环境变量目录

方式 A（管理员模式，最省心）：以管理员身份打开 PowerShell，进入下载目录执行，直接移入自带 PATH 的 Windows 系统目录：

Move-Item .\tran-x86_64-pc-windows-msvc.exe "C:\Windows\tran.exe"

方式 B（普通用户模式）：新建个人工具目录并永久追加至当前用户的 PATH：

New-Item -ItemType Directory -Force -Path "$HOME\bin"; Move-Item .\tran-x86_64-pc-windows-msvc.exe "$HOME\bin\tran.exe"; [Environment]::SetEnvironmentVariable("Path", [Environment]::GetEnvironmentVariable("Path", "User") + ";$HOME\bin", "User")

💡 提示：若本地已安装 Rust，也可直接移动至 $HOME\.cargo\bin\tran.exe，该目录默认已在 PATH 中。

2 新开终端验证与立即使用

新开一个 PowerShell 或 CMD 窗口，直接输入命令即可畅享翻译：

tran rust
1 赋予执行权限并移入系统命令目录

打开 Terminal 终端，进入下载目录，运行以下命令将其移动至系统的全局执行目录：

chmod +x tran-aarch64-apple-darwin && sudo mv tran-aarch64-apple-darwin /usr/local/bin/tran
2 解除 macOS 开发者安全拦截（如遇提示）

若 macOS 弹出“无法打开，因为无法验证开发者”，在终端执行此命令解除隔离属性：

xattr -d com.apple.quarantine /usr/local/bin/tran
3 在任意终端立即使用

执行 tran i 即可进入沉浸式 50/50 TUI 对照翻译：

tran i
1 赋予执行权限并移入全局路径

打开终端进入下载目录，赋予权限并移入 /usr/local/bin：

chmod +x tran-*-linux-* && sudo mv tran-*-linux-* /usr/local/bin/tran
2 验证与体验

验证命令是否已全局就绪：

tran "Simplicity is prerequisite for reliability."
