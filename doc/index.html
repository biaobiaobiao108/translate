告别笨重的翻译软件，尽享纯粹极客的终端极致体验

⚡

CLI 极速秒级查词

智能分流单词与长句。查词立显权威英美双音标、词性分类详尽释义与中英权威双语例句。

🖥️

50/50 左右对等双栏

左右对等双栏布局，左侧输入长文，右侧同步展现对照结果，彻底摆脱传统单行输入框的遮挡与压抑。

📝

工业级文本编辑

集成 tui-textarea 并深度优化，支持 50+ 行长文本、平滑自动折行、全向光标漫游与跨页快速翻页。

🚀

毫秒级长文粘贴

底层事件循环支持终端括号化粘贴（Bracketed Paste），粘贴海量多行大段文字无感注入，绝不误触发网络翻译。

🎯

输入法 (IME) 精准跟随

动态测量全角中文字符与英文字母真实列宽，硬件物理光标与输入法候选框时刻同步在字符最右侧，杜绝下划线干扰。

⭐

本地生词本与历史抽屉

轻量 SQLite 本地存储（~/.translate/history.db），支持一键收藏生词、历史回溯、条目过滤与一键重查。
